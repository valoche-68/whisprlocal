# WhisprLocal 0.1.0 validation

Validated on Linux x86_64 with KDE/XWayland and an NVIDIA RTX 3070, using the OpenWhispr 1.11.0 base. This report contains outcomes only; profiles, tokens, audio, transcripts and detailed runtime logs remain private.

| Area                       | Result                                                                                                                                                                                                                                                                                                           |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Build                      | TypeScript, renderer build and all locale key/placeholder checks pass. Linux AppImage, Debian package and tar archive build successfully.                                                                                                                                                                        |
| Regression checks          | Relevant upstream Whisper, llama, GPU, clipboard, local bridge, self-hosted routing/authentication and Linux autostart tests pass. The local suite covers migration, network policy, CLI/MCP, archive checksums/staging/rollback, ASAR handling and clean/conflicting upstream merges.                           |
| French GPU speech          | An installed multilingual Whisper model transcribes French on CUDA. Repeated transcription reloads the engine after unloading.                                                                                                                                                                                   |
| Idle unloading             | GPU memory is released after the configured five-second idle delay. Disabling unloading retains the same engine process beyond that delay; re-enabling it stops the idle engine.                                                                                                                                 |
| Offline inference          | French GPU transcription and an authenticated self-hosted speech endpoint work inside an OS network namespace with only loopback available.                                                                                                                                                                      |
| Self-hosted language model | A real local llama.cpp server accepts an authenticated chat-completion request.                                                                                                                                                                                                                                  |
| CLI and MCP                | The installed CLI uses the authenticated loopback API. A real stdio MCP session negotiates the protocol, lists 19 tools and calls the health operation.                                                                                                                                                          |
| Profile migration          | A full private backup precedes import into a separate profile. Preferences and local data import; account sessions and cloud credentials do not. Existing models and compatible GPU packs are reused.                                                                                                            |
| Interface                  | French and English main interfaces and official onboarding style were inspected. Account/service UI is removed. The original local CLI integration card remains; the cloud card is removed.                                                                                                                      |
| Network                    | Instrumented main/renderer requests during the tested scenario use loopback and the project's GitHub update check. No official-service or telemetry destination is observed. Speech engines also pass the isolated-network test. This is scenario coverage, not a proof about every possible future interaction. |
| Managed archive update     | A real application archive is staged, the old process exits, the detached helper starts the candidate, and rollback restarts the previous build. Existing profile preferences are preserved. Extraction also passes through the helper loaded from the packaged ASAR.                                            |
| Upstream automation        | The hourly workflow runs successfully. Fixture migrations cover both a clean merge and a conflicting merge; conflicts retain local changes and block publication.                                                                                                                                                |

AppImage updater metadata and artifact checksums are validated. A download/apply cycle against a **public** WhisprLocal release cannot be exercised before the first release is approved and published. Debian packaging is built and inspected; administrator installation is not performed on the validation host. These two delivery paths still need their first public-release smoke test.

Release artifacts remain a draft until human approval. Sources, documentation and built artifacts are the only intended public outputs.

## Français

La validation couvre la transcription française sur RTX 3070, le déchargement après cinq secondes, le maintien en mémoire lorsque désactivé, le fonctionnement sans réseau, les serveurs auto-hébergés authentifiés, la CLI et le MCP local, la migration du profil et la mise à jour d'une installation décompactée avec retour arrière.

L'interface officielle est conservée, en français et en anglais. La carte CLI locale reste disponible ; les comptes et les éléments cloud sont retirés. Les journaux détaillés, profils et transcriptions restent sur la machine de validation.

La première mise à jour depuis une publication publique AppImage et l'installation Debian avec authentification administrateur restent à tester après validation humaine de la publication.
